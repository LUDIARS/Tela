# ビューの拡大率に文字サイズが追従しない

## 目的

2026-09-16 のネイティブビュー実機確認で、同じ書き出しを 3 つの大きさで見ると
文字だけが取り残されることが分かった。

- ウインドウが内容より小さいとき: 図は縮むのに文字は縮まず、箱からあふれて切れる
- ウインドウが内容と同じとき: 意図どおり読める
- フルスクリーン (3840x2160 に 1220x668 を収める = 約 3.1 倍) のとき: カードは 3 倍に
  なるのに文字は 16px のままで、広い箱に小さな文字が残る

`spec_view_document` は書き出しの座標に `scale` を掛けて図を収めるが、文字サイズは
テーマの値をそのまま使うため、拡大・縮小のどちらでも見た目の比率が崩れる。
`--font-size` で手動では合わせられるが、ウインドウの大きさを変えるたびに指定し直す必要がある。

## 完了条件

- 収めるときの倍率に文字サイズを追従させるかどうかを決めて contracts に書く。
  追従させる場合、テーマの文字サイズを基準倍率 1.0 の値として扱い、`--font-size` は
  その基準を変える指定にする。
- 追従させたとき、行の高さと `Layout::lines` が確保する高さも同じ倍率で動くことを確認する。
- 縮小時に文字が箱からあふれないこと、拡大時に文字が箱に対して小さすぎないことを
  実画面のキャプチャで確認する。ウインドウ・等倍・フルスクリーンの 3 つで見る。
- オーバーレイ (spec-view / scene-overlay) 側の見え方が退行しないことを確認する。
  オーバーレイはホストに合わせて縮むので、同じ規則が要るか別扱いかを決める。
