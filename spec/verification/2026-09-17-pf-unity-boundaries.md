# Pf / Unity 分離と仕様ビューの確認記録

価値: UX-TL-W2 / UX-TL-W5。ユーザーが、対象画面と対応する仕様カードを読み、
先頭カードを操作パネルに隠されず確認できる状態を守る。

## 実装内容

仕様カードの図と文字に同じ倍率を適用し、左の操作領域を分離した。
題名はカード内に収まる完全な行を最大3行描く。`Layout::text_scale` は既定1、
有限かつ (0,64]。DPIはホスト境界で一度だけ適用する。
Coreの状態所有者はDocument/Runtime、Pf文書の配置はspec-viewが所有する。
公開 `SceneOverlayConnection` は既存SceneBridgeへ委譲し、接続の所有者を増やさない。
Pfの認証・指示保存・Editor UIは別リポジトリの任意アダプター側に分離した。

## 受け入れ条件

- 小・等倍・大の仕様ビューで文字と図の比率が揃う。
- 最大32グループのボタンがカードと重ならない。
- 内容が変わらない間は再描画を要求しない。
- 不正なpipe名で既存接続を切らない。Scene close / reload / quitは既存所有者が解放する。
- 実画面で読めることと物理入力の所有は、コンパイルだけでは合格にしない。

## 実施した確認

- Visual Studio 2022 x64 ReleaseでWindows view / overlay、Core、全CMakeテストターゲットをコンパイル。
- Unity 6000.0.59f2付属コンパイラーでTela.Editorとbridge契約テストをコンパイル。
- 同じTela.Editor.dllを使い、Pf Editor / tests / optional Tela adapterをコンパイル。
- `git diff | anatomia verify --repo <worktree>`: 全5項目PASS。
- `git diff --check`: PASS。

登録テストは実行していない。現行session-work規則は明示指示なしのテストを禁止し、
今回の指示は残作業の実装であるため、起動・実機・単体・統合テストを合格扱いしない。
サービス操作、main更新、配布物更新も未実施。既存デモは維持した。

## 復旧方法

レビューで不採用ならこのfeature branchの変更を破棄する。統合後に戻す必要がある場合は
変更コミットをrevertして旧配置と描画へ戻す（このセッションではmainへ適用しない）。
Pfの任意アダプターは新公開APIを使うため、Telaを戻す際は併せて外す。
既存の文書形式とpipe wire formatは変更していない。
