# View host

SPEC-TL-VIEW-HOST。対象アプリを起動できないときに、宣言を Tela 自身の通常ウインドウ
（ウインドウ／フルスクリーン）で描く。価値は UX-TL-W5（[product](../ux/product.md)）。

## 目的

Pf の内容を作業対象に重ねて見たいが、ゲーム画面はプレイ中しか出ず、Unity も常に開いて
いるとは限らない。対象が用意できないと「重ねて確認する」機会そのものが無くなる。
Tela が自分のウインドウで内容を描けば、対象なしでも実寸で読める。重ねる用途は
オーバーレイ（[host-overlay](../ux/host-overlay.md)）が引き続き担い、こちらは置き換えない。

## 使い方

```sh
tela_view --font <file.ttf> --spec-view <file> [--fullscreen] [--width W] [--height H]
          [--font-size 8..96] [--title <text>] [--seconds 1..3600]
```

大きさを指定しなければ、書き出しに入っている内容の寸法をそのままウインドウの大きさにする
（縮小が起きないので文字が読める）。`F11` でフルスクリーンと元の大きさを行き来し、
`Esc` で閉じる。

## 契約

規則は [contracts](../contracts.md) の SPEC-TL-VIEW-HOST。

- ビューは自分の表示面と入力をすべて所有する。オーバーレイの透過・専有の区別は持ち込まない。
  別ウインドウの入力領域を作らないので、宣言したボタンはそのまま押せる。
- ビューポートはクライアント領域とし、DPI はウインドウから取る。大きさ・DPI・表示状態・
  フォーカスが変わらなければビューポートを作り直さない。
- 宣言が変わっていないフレームは提出しない。最小化・非表示の間は描かない。
- 閉じるとホストを失ったときと同じように表示と入力所有を解除する。
- 1 回の実行につき内容は 1 つ。font と内容が揃わない起動は、空のウインドウを出さずに失敗させる。

## テキストの行数

Layout の `lines` が、そのテキストが確保する行数を表す。描画側（Pictor）は幅に対して
折り返す一方、箱が 1 行分しか無いと残りが落ちるため、折り返したいテキストは行数を宣言する。
既定は 1 行で、従来の見え方を変えない。上限は 64 行。
